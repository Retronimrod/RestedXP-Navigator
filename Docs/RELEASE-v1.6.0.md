# RestedXP-Navigator v1.6.0

## World Marker Intelligence

- Automatic safe NPC anchoring for interaction objectives when the exact NPC nameplate is already visible.
- Correct NPC screen height without restricted nameplate measurements.
- Automatic fallback to normal C_Navigation/user-waypoint guidance.
- Configurable marker scale, distance label, beam range and NPC anchor range.

## New Control Center

A completely new standalone settings window with a modern sidebar/card layout, dedicated World Marker configuration and a live Blizzard-style marker preview.

## Safety and licensing

- No automatic combat actions or protected API bypasses.
- No automatic nameplate-CVar changes.
- No restricted nameplate geometry reads.
- No third-party addon source code or assets are included.
- Blizzard PingUI atlases are referenced through the normal WoW UI API.
