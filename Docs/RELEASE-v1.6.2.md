# RestedXP-Navigator v1.6.2

## Semantic World Markers

The in-world marker now changes its symbol and color to match the current
objective while retaining the same established marker form.

- Quest accept: yellow !
- Quest turn-in: yellow ?
- Combat/kill: red crossed swords
- Vendor: green money bag
- Innkeeper/Hearthstone: green hearth symbol
- Flight: green wing
- Default/travel: blue diamond

The approved marker artwork is separated into head, beam and ground-ring assets
so close-range positioning and beam scaling continue to work normally.
