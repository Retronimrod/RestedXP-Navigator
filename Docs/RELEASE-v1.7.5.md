# RestedXP-Navigator v1.7.5

- The optional Shortest Path Forever bridge now supports SPF API v2 alongside v1. This restores bridge activation, route preview, and display controls with compatible SPF releases.
- The bridge can still be switched off if the SPF API becomes unavailable.
- The diagnostic export records SPF and bridge versions, load status, API compatibility, display settings, and route status. Opening it hides the settings panel until the export is closed.
- The first login after updating shows a localized notice about the fix and how to include a bug report in a CurseForge comment.
