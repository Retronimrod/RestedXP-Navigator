# RestedXP-Navigator v1.7.4

- The download includes RestedXP-Navigator and the optional Shortest Path Forever Bridge. Shortest Path Forever is installed separately.
- Configure the bridge under Modules. When available, the bridge offers one-time activation after the update.
- Use SPF's route for the current step and retain the Navigator preview for upcoming steps on the world map and minimap. SPF travel information remains visible in the quest tracker.
- The route preview returns to the Navigator settings when closed.
- The Navigator and bridge use the WoW client language. This update expands translations across the 12 supported locale variants.
- Removed the Share Target bar and raid-marker buttons from the Navigator.
