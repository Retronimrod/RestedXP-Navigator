# RestedXP-Navigator v1.7.2

- The beacon is now the sole world marker design. Existing profiles use it automatically.
- Removed the legacy style selector, personal raid-symbol picker, ground-ring settings, and obsolete marker color page.
- The options and setup previews show the beacon with the current visibility, scale, distance, and beam settings.
- The optional close-range beam appears on valid, on-screen waypoints. The compact action icon remains available at long range and at the screen edge.
