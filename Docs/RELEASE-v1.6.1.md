# RestedXP-Navigator v1.6.1

## Grounded World Markers

World markers now gain a soft oval ground ring at close range. The ring sits at
the base of the existing marker stem and inherits the current marker color,
making the destination feel visually anchored to the terrain.

### New
- Original oval ground-ring asset
- Automatic marker-color tinting
- Ground Ring toggle in the modern World Marker settings
- Adjustable ring size

The implementation is presentation-only and does not use restricted frame
geometry, automated player actions, or third-party addon code/assets.
