# RestedXP-Navigator v1.4.0

RestedXP-Navigator 1.4.0 expands the navigation layer with dedicated quest-object markers and a new Grind XP HUD.

## Highlights

### Quest-object / collectible markers
- RestedXP object-location loops can be rendered as individual markers instead of connected route lines.
- Object classification for crystals/minerals, chests/caches, plants/herbs, mushrooms, eggs, containers, remains/corpses and neutral fallback objects.
- Markers on both World Map and Minimap.
- Nearest-object highlighting and contextual tooltips.
- Existing farm, patrol, search and normal navigation overlays remain unchanged when a loop is not identified as an object-collection loop.

### Grind XP HUD
- Dedicated XP progress block for RestedXP grind steps.
- Live current/target XP display.
- Percentage progress bar.
- Grind instruction text.
- ETA is hidden while a grind step is active.
- Improved text size, progress-bar size and vertical spacing for readability.

## Existing navigation features
- Minimap and World Map routing.
- On-screen HUD navigation.
- +1 to +6 future RestedXP goals.
- Smart travel routing for Hearthstone, flights, Zeppelins, ships and portals.
- Farm, patrol and search-area overlays.
- Corpse-run navigation.
- Diagnostics and bug-report export.

## Requirements
- WoW Forever 1.60.1
- RestedXP Guides / RXPGuides
- TomTom is not required

## Installation
Download `RestedXP-Navigator-v1.4.0.zip`, extract the included `RXP_Navigator` directory into `Interface/AddOns`, and enable both RestedXP Guides and RestedXP-Navigator.

## Important
RestedXP-Navigator is an unofficial companion addon. It does not include or redistribute RestedXP guide content and does not automate movement, combat, interactions or gameplay input.
