# RestedXP-Navigator v1.4.0

Stable release based on the currently tested in-game 1.4.0 development build.

## Highlights
- Quest-object / collectible markers for RestedXP object-location loops on World Map and Minimap.
- Object classification, contextual tooltips and nearest-object highlighting.
- Dedicated Grind XP HUD with current/target XP, percentage progress and action text.
- ETA is hidden during grind steps while normal navigation retains ETA.
- Improved Grind HUD text size, progress bar size and spacing.

## Release cleanup
- TOC version synchronized to 1.4.0.
- Internal runtime/diagnostics version synchronized to 1.4.0.
- Obsolete beta labels removed from user-facing inspector output.
- Documentation updated to the stable 1.4.0 release.

## Requirements
- WoW Forever interface 16001 / 1.60.1
- RestedXP Guides / RXPGuides
- TomTom is not required
